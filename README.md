## 📖 Overview
<a id="overview"></a>

**ChemSketch** is an innovative educational software designed for students and educators in the field of chemistry, available for Windows. This powerful tool enables users to draw and study the structures formed by chemical elements, making it an essential resource for learning chemistry. The **latest version** of ChemSketch is packed with features that enhance understanding of chemical compounds and their interactions. 

With its user-friendly interface inspired by Microsoft Office, ChemSketch allows learners at all levels—from school to university—to visualize and manipulate chemical structures seamlessly.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Chemical Structure Design** — Draw and visualize chemical structures, reactions, and schemes with ease.
- **IUPAC Name Generation** — Automatically generate IUPAC names for molecules containing up to 50 atoms and 3-ring structures.
- **Molecular Properties Prediction** — Predict key properties such as molecular weight, formula weight, and density for individual structures.
- **Integrated Dictionary** — Access tens of thousands of systematic, trivial, and commercial names within the software.
- **Professional Report Generation** — Combine structures, text, and graphics to create professional reports.

### Advanced Features:
- **Import/Export Functionality** — Import and export structure files in various formats for seamless integration with other software.
- **User-Friendly Interaction** — Utilize a drag-and-drop interface to create bonds by simply moving atoms.
- **3D Model Creation** — Transform 2D structures into 3D models for a more comprehensive understanding of molecular geometry.
